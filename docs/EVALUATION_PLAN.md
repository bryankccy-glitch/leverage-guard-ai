# 評估計畫

## 1. 自動評估（已實作）

執行：`cd apps/api && .venv/bin/python ../../scripts/run_evaluation.py` → `data/evaluation/latest_results.json`（後台 `/admin/evaluation` 顯示）。資料集：`data/evaluation/dataset.json`（虛構情境，人工標註）。

### 最新結果（2026-11-26 實際執行）

| 指標 | 結果 |
|---|---|
| 金融計算正確率（9 個 golden cases、27 個數值） | 27/27 |
| 計算延遲（後端單次，含規則引擎） | p50 0.49 ms，最大 6.16 ms |
| 法律事件正確率（5 個情境、15 個應出現／不應出現檢查） | 15/15 |
| 引用正確率（規則引用逐字比對官方條文） | 30/30；另有 2 條規則沒有官方來源，標示待查證 |
| 生效版本正確率（當沖稅率依日期） | 4/4 |
| 投資建議請求偵測 | recall 1.0、誤判率 0（12 句） |
| AI 輸出審查（建議、概念錯誤） | 6/6（第一次執行 5/6，發現「建議你現在賣出」漏攔，已修正） |

**限制**：資料集小，而且是開發者自己標註，只能證明「已知案例沒有退步」，不能代表在真實使用下的正確率。法律判斷部分尚未經具金融法律專業的人員複核（`reviewer: null`）。

## 3. 人機互動評估（設計，尚未執行）

研究問題：互動式金融法律模擬器，是否比傳統法規文字或一般試算工具，更能幫助使用者理解交易責任？

| 條件 | 內容 |
|---|---|
| A | 法規與契約原文 |
| B | 一般融資試算工具（只有數字） |
| C | LeverageGuard AI |

- 任務：辨識融資借款、理解維持率、區分追繳與處分、理解本金虧損與剩餘債務、理解當沖未沖銷、找出法源。
- 量測：任務正確率、完成時間、法律與財務理解測驗、信心校準、SUS。
- 受試者只使用虛構情境，不提供真實帳戶或個人金融資料。
- 若作為正式學術研究，需先確認研究倫理審查（IRB）。
- **沒有實測前，不宣稱任何改善幅度。**
