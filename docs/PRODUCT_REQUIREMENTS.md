# 產品需求（PRD）— LeverageGuard AI

> AI 金融交易風險與法律責任情境模擬平台｜Know the Risk. Understand Your Rights.｜看見風險，理解責任，掌握權益。

## 1. 使命

協助投資人在承擔金融交易風險之前，理解市場變動可能造成的財務損失、契約責任、法律義務與投資人權益。第一階段聚焦台灣證券市場的**融資交易**與**現股當日沖銷**。

## 2. 不做的事（硬性限制）

個股買賣建議、股票推薦、進出場訊號、最佳交易價格或槓桿比例、股價預測、保證獲利、自動下單、鼓勵增加槓桿、規避交割或清償的方法。Copilot 與 Review Agent 以確定性規則攔截這類請求與輸出（`apps/api/app/agents/guards.py`）。

## 3. 目標使用者

| 使用者 | 核心需求 | 本版支援 |
|---|---|---|
| 一般投資人 | 試算風險、理解追繳與交割、查規定、看懂契約 | 模擬器、實驗室、時間軸、法律中心、契約分析、報告 |
| 證券商法遵／客服 | 標準化風險說明、可追溯紀錄 | 規則版本、稽核紀錄、專業版報告 |
| 法律專業人士 | 規則檢索、契約條款、責任時間軸 | 法規全文、規則審查後台、引用驗證 |

以上為目標客群，**未宣稱已被任何機構採用**。

## 4. 問題與對應功能

| 問題 | 功能 |
|---|---|
| P01 不知道融資會放大虧損 | 融資模擬器：本金損益率、KPI、首頁互動預覽 |
| P02 不清楚維持率怎麼算 | 每個數字可展開公式；引用操作辦法第 53 條 |
| P03 混淆追繳門檻、補繳期限、處分條件與成交價 | 時間軸分開呈現：跌破 → 通知 → 二營業日期限 → 期限當日判斷 → 次一營業日處分 |
| P04 以為本金虧完就沒有債務 | 處分結算：剩餘債務、通知補足、限期清償、申報違約（第 55、81 條） |
| P05 不了解當沖未沖銷的責任 | 當沖模擬器：未沖銷部位全額交割、先賣後買強制買回（作業辦法第 1、7、9、13 條） |
| P06 契約術語難懂 | 契約分析：原始條款＋頁碼＋分類＋白話（引用必須存在於文件） |
| P07 規定會變 | 規則版本、生效期間、法規變動監察、示範版本比較 |
| P08 計算機沒有法律後果 | 規則引擎＋時間軸 |
| P09 AI 可能編造條文 | 引用逐字驗證；AI 不能改數字；Review Agent |
| P10 極端情境如何轉為法律責任 | 極端情境實驗室（12 個預設、播放、比較） |

## 6. 使用者旅程（主要）

1. 訪客在首頁拖動股價，看見維持率與法律事件變化（不需登入）。
2. 進入融資模擬器，輸入參數；滑桿即時預覽，後端正式計算。
3. 跌破門檻時右欄出現法律後果與官方條文；點「在實驗室推演」看完整時間軸。
4. 登入後儲存情境，按「AI 白話分析」：Agent 進度即時顯示。
5. 產生投資人版或專業版報告，下載 PDF。
6. 上傳證券商契約，查看條款、權利義務與「文件中未找到」的項目。
