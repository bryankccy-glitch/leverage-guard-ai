# 金融公式規格（financial_engine）

所有金額使用 Python `Decimal`（後端，Source of Truth）與 `Decimal.js`（前端即時預覽）。金額取到元；百分比取到小數兩位。`float` 一律拒絕（`rounding.D()`）。

## 融資（單一部位）

| 符號 | 意義 |
|---|---|
| P0 | 買入價格 |
| Pt | 模擬價格（官方規定為計算日收盤價，本系統以模擬價格代入並標示） |
| Q | 股數 |
| F | 融資比率 |
| D | 融資金額 = P0 × Q × F（依「融資金額計算單位」捨去，預設 1 元） |
| C | 自備本金 = P0 × Q − D |
| M | 模擬市值 = Pt × Q |
| T | 追繳門檻（規則引擎參數，現行 1.30） |

| 項目 | 公式 | 依據 |
|---|---|---|
| 擔保維持率 | (M ＋ 抵繳市值) ÷ D × 100% | 操作辦法第 53 條（單一部位、無融券化簡） |
| 追繳門檻股價 | (D × T − 抵繳市值) ÷ Q | 由第 53、54 條推導；**不是確定的斷頭價** |
| 取消追繳股價 | (D × 1.66 − 抵繳市值) ÷ Q | 第 55 條第 1 項第 4 款 |
| 補繳差額 | D − Pt × Q × F − 抵繳市值 × F（僅在維持率低於門檻時） | 第 54 條第 2 項 |
| 未計費用損益 | M − P0 × Q | |
| 淨損益 | 未計費用損益 − 買進手續費 − 賣出手續費 − 交易稅 − 利息 | |
| 本金損益率 | 淨損益 ÷ C × 100% | |
| 利息 | D × 年利率 × 持有天數 ÷ 年基準（365 或 360） | 計息方式依契約，參數可調 |
| 剩餘債務 | max(0, D ＋ 利息 ＋ 違約金 − 處分淨所得 − 可抵充款項) | 第 55 條第 2 項、第 81 條 |
| 溢額發還 | max(0, 處分淨所得 ＋ 可抵充款項 − 應清償債務) | 第 55 條第 2 項 |
| 違約金 | 應補差額 × 融資利率 × 10%（自違約日至清償日） | 第 82 條 |
| 整戶維持率 | (Σ市值 ＋ 抵繳市值) ÷ Σ融資金額 | 第 53 條；**不可直接平均各部位** |
| 抵繳折算 | 公債九折；地方債、公司債、金融債七折；可融資上市櫃證券七折；不可融資者五折 | 第 59 條 |

## 當沖

| 項目 | 公式 | 依據 |
|---|---|---|
| 已沖銷股數 | min(買進股數, 賣出股數) | 作業辦法第 1 條 |
| 已沖銷毛損益 | (賣價 − 買價) × 已沖銷股數 | |
| 當沖交易稅 | 已沖銷賣出金額 × 1.5‰（2017-04-28～2027-12-31） | 證交稅條例第 2-2 條 |
| 未沖銷賣出交易稅 | 未沖銷賣出金額 × 3‰ | 第 2 條（不符合同數量條件） |
| 手續費 | max(最低手續費, 成交金額 × 費率 × 折扣)，無條件捨去到元；依股數分攤到已／未沖銷 | 券商契約（可調假設） |
| 交割應付款 | 未沖銷買進價金＋手續費 − 已沖銷淨損益 − 未買回賣出淨價款 | 作業辦法第 1 條（差價交割） |
| 資金缺口 | max(0, 交割應付款 − 可用資金)；**預估，不等於違約** | |
| 強制買回成本 | 假設買回價 × 股數 ＋ 手續費 ＋ 借券費（費率上限 7%） | 第 7、9、13 條 |

## 邊界處理

除以零回傳 `None` 並在介面顯示「—」；負數、比率超出 (0,1)、非整數股數、缺少利率（警示、不計利息）、缺少門檻規則（409 錯誤，要求人工確認）都有欄位層級錯誤訊息。

## 測試

`apps/api/tests/test_financial_engine.py`：golden cases（每個期望值附手算過程）、邊界、Hypothesis 性質測試（相同輸入相同結果、市值下降維持率不升、不出現 NaN／無限、費用非負、股數守恆）。
